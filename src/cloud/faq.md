## 云账号和 DMP 本地账号是什么关系？

两套独立的账号。

- **DMP 本地账号**：登录这台 DMP、决定权限和房间归属
- **云账号**：云端身份，用来保存和同步云端数据

绑定只是把两者关联起来。云账号不能绕过 DMP 的权限体系，也不能替代本地账号。

## 一定要有云账号才能用 DMP 吗？

不是。DMP 可以完全本地使用。云账号只增加云端收藏、令牌、管理员、预留位和云存档这些能力。

## 云账号和 DST Block 账号是同一个吗？

是统一身份。同一个用户名、邮箱和密码可以在 DMP Cloud、DST Block 以及支持统一登录的 DMP 中使用。

## 绑定云账号会修改本地用户名和密码吗？

不会。绑定只保存云账号关联关系和加密后的云 token，本地用户名、密码、权限都不变。

## 绑定后会自动上传本地收藏吗？

不会。绑定不会自动上传收藏，也不会覆盖本地数据。需要手动执行同步。

## 用云账号登录 DMP 后会自动同步收藏吗？

`v3.2.2` 的云账号登录只刷新套餐和配额，不会自动覆盖本地收藏。第一次使用或换设备后，请到「房间收藏」页手动执行一次同步。

## 一个云账号能绑定几台 DMP？

一个云账号可以绑定多台 DMP，用于多设备共享同一份云端数据。

但在同一台 DMP 上：

- 一个本地用户只能绑定一个云账号
- 一个云账号只对应一个本地用户

## 解除绑定会删除云端数据吗？

不会。解除绑定后：

- 本地收藏保留
- 云端收藏保留
- 只是停止同步，需要重新绑定才能继续使用云端数据

## 一台设备删除收藏，其他设备会跟着删除吗？

会，但取决于同步方式：

- 「立即同步」会双向传播删除
- 「上传本地收藏」会把本地删除传播到云端，但不会拉取云端删除
- 「下载云端收藏」会应用云端删除，但不会上传本地删除

## 提示「收藏配额已满」怎么办？

配额只统计未删除的云端收藏。可以先删除不需要的收藏释放配额，或者在云端升级套餐。

## 云存档为什么上传不了？

检查这几点：

- 当前套餐是否为旗舰版（云存档仅旗舰版支持）
- 云端是否已经保存了 `5` 个存档
- 单个 zip 是否超过 `50MB`

## 导入云存档会覆盖当前房间吗？

不会。导入会创建一个新房间，并切换到新房间，当前房间不受影响。

## 云账号密码忘了怎么办？

在云账号登录页点击「忘记密码」，通过注册邮箱验证码重置。重置后其他设备的云会话会失效。

如果忘记的是 DMP 本地账号密码，请参考[忘记密码](../faq/dmp/forget-password.md)。

## 云服务不可用时还能登录 DMP 吗？

可以。以下情况 DMP 会尝试回退到本地账号校验：

- 网络错误
- 请求超时
- 云服务返回 `5xx`

如果云服务明确返回账号或密码错误，则不会回退。也可以直接使用「本地账号」标签登录。

## 为什么超过一段时间没用，就要重新登录云账号？

云账号的 refresh token 有效期为 `30` 天。超过 `30` 天未使用平台，需要重新用云账号登录一次。重新登录不会影响本地数据。

## 云端数据安全吗？

- 云账号密码使用 `Bcrypt` 存储
- 云服务签发独立的 access / refresh token
- DMP 把云 token 加密后保存在本地数据目录
- 云 API 只由 DMP 后端调用，浏览器不接触 refresh token
- 云站点不会直接读取 DMP 的本地数据库

## 兑换码从哪里获得？

基础版默认免费开通，不需要兑换码。高级版、旗舰版的兑换方式与获取渠道以[云账号官网](https://dmp-cloud.miraclesses.top/)为准。

## 云账号套餐会过期吗？

当前套餐为一次性永久套餐，不会自动降级。已有数据不会因为套餐调整被删除；超出配额时无法继续新增。
