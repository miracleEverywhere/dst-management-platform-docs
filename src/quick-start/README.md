::: info
快速上手是一套从零开始的教程：从选择云服务器，到部署饥荒管理平台、配置房间并启动游戏。
:::

本教程面向第一次接触云服务器和饥荒专用服务器的用户，不要求有 Linux 或开服经验。每一步都会尽量给出完整命令和界面截图；想了解某个功能的设计和细节时，可以到[深度文档](../docs/)查看对应页面。

完成下面 5 步，就算是小白，也可以开出一个完美的饥荒专用服务器：

1. [服务器选择](./server.md)：选购并登录云服务器
2. [部署安装](./install.md)：安装饥荒管理平台和饥荒服务端
3. [令牌申请](./token.md)：申请游戏令牌，也可以先用默认令牌跳过
4. [游戏设置](./setting.md)：注册账号、安装游戏、创建房间、配置模组并启动
5. [开通防火墙](./firewall.md)：放行平台与游戏端口，让玩家可以直连

::: tip
如果你在使用上遇到了问题，可以[加群讨论](../faq/group.md)
如果你遇到了bug或有好的想法，请前往[Github](https://github.com/miracleEverywhere/dst-management-platform-api/issues)留下issue
:::
