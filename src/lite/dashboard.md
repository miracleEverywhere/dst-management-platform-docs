控制面板是 Lite 使用频率最高的页面，集中展示房间信息、服务器状态和世界启停操作。

页面每 **10 秒**自动刷新一次，无需手动操作。如果某个接口失败，页面顶部会出现黄色提示条，点击 **重试** 可重新拉取全部数据。

## 房间概览

房间卡片展示当前房间的核心信息：

| 字段 | 说明 |
| --- | --- |
| 房间名 / 房间描述 | 来自[房间设置](./room.md)，描述为空时显示"暂无房间描述" |
| 更新游戏 | 后台执行 `manual_update.sh` 更新饥荒服务端，见[更新游戏](#更新游戏) |
| 玩家数量 | `在线人数 / 最大玩家数`，鼠标悬停可查看在线玩家昵称 |
| 游戏模式 | 生存、无尽、荒野、轻松、暗无天日、熔炉、暴食 |
| 直连地址 | 显示"点击复制"，点击后复制 `c_connect(...)` 到剪贴板 |
| 模组数量 | 统计 `modoverrides.lua` 中 `["workshop-数字"]` 的条目数 |
| 玩家投票 | 对应房间设置中的"玩家投票" |
| 自动暂停 | 对应房间设置中的"自动暂停" |

![控制面板-房间](assets/dashboard-room.webp)

::: tip
在线玩家由后台每 2 分钟向游戏注入一次查询命令获得，因此人数和昵称最多会有 2 分钟延迟；世界未运行时显示 `0`。
:::

如果还没有配置房间（房间名为空），卡片会变成引导状态，点击 **去配置** 跳转到房间设置。

## 系统指标

三张指标卡片分别展示平台与服务器的资源占用：

![系统指标](assets/dashboard-metrics.webp)

| 卡片          | 数据来源     | 说明                        |
|-------------|----------|---------------------------|
| DMP Lite 内存 | 平台进程 RSS | 只统计 `dmp-lite` 自身，不包含游戏进程 |
| CPU 使用率     | 整机 CPU   | 游戏启动瞬间会明显升高               |
| 内存使用率       | 整机内存     | 建议配合虚拟内存使用                |

- 每张卡片带一条迷你曲线，保留最近 30 次采样
- CPU / 内存状态阈值：低于 75% 显示"正常"，75%～90% 显示"偏高"，90% 及以上显示"过高"
- 刚打开页面时显示"等待数据"，第一次接口返回后变为实际数值

::: info
Lite 平台本身通常只占用 10MB 左右内存。如果整机内存吃紧，主要占用来自饥荒服务端，可通过 `run.sh` 的 `[6]` 开启虚拟内存。
:::

## 世界卡片

控制面板底部是地面世界与洞穴世界两张卡片：

![地面洞穴世界](assets/dashboard-worlds.webp)

- 右上角标签显示该世界是 **主世界** 还是 **从世界**
- 状态区展示"世界运行中 / 世界未运行"，运行中时状态点为绿色呼吸效果
- **启动世界**：以 `screen` 会话启动对应世界（会话名 `DMP_LITE_<世界名>`）
- **关闭世界**：向游戏发送 `c_shutdown()`，最多等待 15 秒，仍未退出则强制结束 `screen` 会话
- 启动 / 关闭执行期间，按钮进入 loading 状态并禁止重复点击；操作完成后会自动重新读取世界状态

::: warning
以下情况 **启动世界** 按钮不可用：

- 该世界正在运行
- 该世界正在执行启动 / 关闭操作
- 世界的 `leveldataoverride.lua` 为空（提示"世界参数为空，暂不可启动"）
:::

世界尚未配置时，卡片显示"该世界还没有配置，配置完成后即可启动"。

## 更新游戏

点击房间卡片右上角的 **更新游戏**，会在后台执行：

```bash
bash ./manual_update.sh
```

该脚本通过 SteamCMD 校验并更新 `dst/` 下的饥荒服务端文件，**更新的是游戏，不是 Lite 平台**。

::: warning
更新前请先关闭地面与洞穴世界。更新期间没有进度条，页面只会提示"执行成功"（表示脚本已开始执行），实际耗时取决于网络。
:::

更新完成后，顶部游戏版本标签会从黄色变为绿色（如果已是最新版本）。平台自身的更新请使用 `run.sh` 的 `[4]`。

## 游戏版本

控制面板所属的顶部导航栏会显示当前游戏版本：

- 拿到的是 `dst/version.txt` 中的本地版本
- 与后台每 2 小时拉取一次的官方最新版本比较
- 颜色含义见[注册登录与首次开服](./first-use.md#界面构成)
