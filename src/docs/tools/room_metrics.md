房间监控用于查看当前房间各世界在一段时间内的资源占用曲线

## 开启监控

房间监控默认关闭，需要先在[房间设置](../setting/room.md#房间资源监控)的**系统设置**中开启**房间资源监控**

开启后，平台会按世界记录 CPU、内存和磁盘占用，数据每分钟采集一次

## 查看监控

选择要查看的房间后，打开**平台工具 - 房间监控**

- 时间范围：可以选择最近 `1`、`3`、`6`、`12` 或 `24` 小时的数据
- 世界标签页：按世界分别展示，地面和洞穴需要切换标签查看
- 刷新：重新拉取当前时间范围的数据

每个世界会展示四张图表：

| 图表 | 说明 |
| --- | --- |
| CPU 使用率 | 该世界游戏进程的 CPU 占用百分比 |
| 内存使用率 | 该世界游戏进程的内存占用百分比 |
| 内存占用 | 该世界游戏进程实际使用的内存大小 |
| 磁盘占用 | 该世界存档与相关文件占用的磁盘空间 |

::: warning
房间未启动、未开启房间资源监控，或还没有采集到数据时，页面会提示「暂无监控数据」

当前房间没有世界时，页面会提示「没有可监控的世界」
:::

::: tip
房间监控的数据保存在平台内存中，平台重启后历史曲线会清空
:::
