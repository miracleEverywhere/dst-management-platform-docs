:::info
该功能于`v3.1.6`加入，管理员安装`tmi`插件后使用
:::

此功能类似于游戏中的`Too Many Items`模组(T键)，你可以任意的执行一些游戏命令，为指定的玩家刷一些物品

:::caution
滥用此功能会极大的减少游戏寿命，并可能导致游戏崩溃，请合理使用
:::

使用该功能前，你需要选择一个在线的玩家，并选择一个世界来执行饥荒远程命令

部分命令例如**切换季节**、**切换时间**等无需选择玩家

![更多物品](assets/tmi-overview.webp)

页面左侧为物品栏，左键点击可以给玩家一个物品，右键可以选择数量

:::tip
从`v3.2.2`开始，物品图片由平台内置的 TEX 解包生成，不再需要 Stex 工具

TEX 解包需要系统提供 `apt`、`unzip` 等命令（Ubuntu、Debian 等）；其他系统可能只能使用基本功能，无法显示物品图片
:::

![给与多个](assets/tmi-right-click.webp)

你也可以切换标签栏，查看不同种类的物品

![切换种类](assets/tmi-more-items.webp)

右侧则为一些预设的命令，点击即可执行

![预设命令](assets/tmi-console.webp)
