::: info
该功能于`v3.2.2`加入
:::

保存一个房间作为模板，方便下次开相似的档

可以在房间总览页面收藏

![房间总览收藏](assets/favorite-rooms.png)

也可以在房间收藏页面收藏，收藏前必须选中一个房间

![房间收藏页面收藏](assets/favorite-current-page.png)

该页面允许的操作：

- 使用收藏创建房间
  - 即应用选定的收藏作为模板，创建一个新房间
- 查看模组
  - 查看收藏房间中启用的模组
- 修改备注
- 删除
