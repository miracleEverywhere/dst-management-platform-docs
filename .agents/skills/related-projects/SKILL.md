# 总则
在处理涉及前端逻辑的问题时，你可以查阅前后端源码以获取准确信息，但**绝对不能修改前后端代码**。

# 前端项目
需要先确认当前系统的类型

前端项目名为dst-management-platform-web，在本机磁盘

如果当前系统是macos，则位于~/OpenIdeaProjects/dst-management-platform-web

如果当前系统是windows，则位于%USERPROFILE%\OpenIdeaProjects\dst-management-platform-web

## 后端项目
需要先确认当前系统的类型

前端项目名为dst-management-platform-api，在本机磁盘

如果当前系统是macos，则位于~/OpenIdeaProjects/dst-management-platform-api

如果当前系统是windows，则位于%USERPROFILE%\OpenIdeaProjects\dst-management-platform-api
